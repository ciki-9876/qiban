# 栖伴 v0.9.0 测试版安装

四端使用同一批栖伴账号。用户名、密码和 AI 密钥请在应用中自行输入，不需要发送给开发者。默认服务地址为 `https://81.70.181.205`。

服务器已启用 v0.9.0 原生接口，安装应用可以连接注册和登录；实际服务器版本和各端验证范围见 [测试报告](TEST-REPORT.md)。离线功能用于已加载内容和当前文字草稿，创建目标、归档、AI 及附件上传需要联网。

## Android 10 及以上

把交付的 `app-debug.apk` 传到安卓手机后打开，按系统提示为当前文件来源允许此次安装。应用名称为「栖伴测试版」，安装后可关闭该来源的安装权限。

这是使用测试签名的 APK，不需要在手机或电脑安装 Android Studio。更新时使用同样签名的包覆盖安装；卸载会删除手机里的未同步草稿。

本次新增 Cookie 隔离的构建与先前 APK 的公开签名证书不同，Android 会拒绝直接覆盖。服务器升级已解决注册来源错误，请继续使用已安装且正常登录的应用；若需要更换测试包，先同步或导出未同步草稿，再由本人卸载和安装，用原账号登录。

## Windows 10 / 11 x64

打开 `Qiban-0.9.0-beta.1-windows-x64-setup.exe`，按安装向导操作。也可以把便携 ZIP 完整解压到自己的文件夹后运行其中的栖伴程序。

测试版没有商业代码签名，系统可能显示来源提示。安装前可将文件摘要与 [测试报告](TEST-REPORT.md) 对照；不要运行来源或摘要不一致的安装包。便携版仍按 Windows 用户保存加密会话和草稿，并不将账号数据放进便携 ZIP。

## Web

在浏览器打开 `https://81.70.181.205`。支持安装的浏览器可以使用地址栏的安装按钮或菜单里的「安装应用」。iPhone 使用 Safari 的「分享 → 添加到主屏幕」。

应用安装入口取决于浏览器；普通浏览器访问保留全部 Web 功能。切换账号前完成同步，或按冲突提示导出草稿。不要清除浏览器数据来处理未同步内容。

## iOS 16 及以上

完整 Xcode 工程在 `clients/mobile/ios/App/App.xcodeproj`。模拟器构建仅用于 Mac 上的 iOS Simulator，不能直接安装到 iPhone。

真机安装需要你本人完成：打开 Xcode 接受首次协议并配置组件，在 Xcode 登录自己的 Apple ID，连接并信任 iPhone，以及按手机提示启用开发者模式。免费个人签名的配置描述文件七天到期，需要重新构建和安装；无需购买开发者会员。[Apple 说明](https://developer.apple.com/help/account/basics/about-your-developer-account/)

随后由开发者选择你的开发团队并构建、安装测试应用。Apple ID 密码、验证码及设备密码无需提供给开发者。具体工程操作见 [手机工程说明](mobile/README.md)。

## 草稿与导出

「已保存到本机」表示内容还可能等待上传；「已同步到账号」表示云端已确认。冲突时先导出草稿，再重新加载云版本。退出账号按应用提示处理未同步内容。

手机使用系统文件选择器导入，通过系统保存或分享导出；Windows 使用另存为；Web 下载历程文件，浏览器支持时也提供系统分享。手机单次原生文件导出上限为 16 MiB，大附件导出需要在 Web 或 Windows 完成。
