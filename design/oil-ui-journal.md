# 栖伴 · 航海手账 UI

设计北极星：打开栖伴，就像翻开自己的航海手账；看清今天的一程，安静地做完它。

## 范围与方向

个人目标管理与陪伴产品，中文优先，覆盖手机、桌面和 Web。延续用户已确认的远航题材与栖栖、船、浮标、岛资产，不重新探索无关品牌方向。优化 UI，沿用账号、草稿、目标、归档、AI/博查及附件流程。

参考任务类产品 Things 的“专注今天”定位（https://culturedcode.com/things/），以及 Finch 的角色陪伴机制（https://finchcare.com/）。只借鉴产品组织思路，不复制页面、配图或素材。栖伴的区别是以航程串联目标，并把一次完成变成船的前进。

## 系统规则

- 色彩来自手账纸、海面和岛上植被。白天纸色 #f6f4ed，墨色 #223b35，行动绿 #355b47；夜间 #101f24，文字 #f2eee4，行动浅绿 #c2d5b3。珊瑚红仅用于航行标记、按住过程和错误相关提示。
- `style.css` 顶部是唯一全局 token 定义。保留原有变量名，场景与旧编辑器复用。早期样式归入 `@layer legacy`，新的布局与共享控件使用明确的高优先级规则，不依靠不断增加选择器权重。
- 中文标题使用系统宋体回退，正文使用系统无衬线，不下载字体；正文 15–16px，辅助内容至少 13px，输入 16px。圆角控件 12px，表面 16–20px，阴影仅用于浮层。原有 SVG 图标保持画法一致。
- 桌面左侧导航，海景与当前行动分栏；900px 以下恢复底部导航。海图以航线/当前航程组织，日志以时间和内容组织，群岛保持一致的目标条目。
- 登录与注册共享主应用色彩、输入框、按钮与反馈；保留账号安全和 AI 服务说明，放进可展开说明区。
- 不引入网络字体、远程素材、统计 SDK、原生权限或新的运行时依赖。

## 状态与动态

保留长按升帆、取消长按、下锚、完成和返航的状态反馈。新进入时 320ms 轻移入；弹窗 220ms 从下方进入；按钮按下 160ms 位移，导航选中颜色过渡 160ms。所有动效尊重 `prefers-reduced-motion`。这是工作界面，不增加滚动叙事。

## 减法

去掉“群岛 / 我的群岛”重复标题、卡片倾斜、普通卡片重阴影、多余边框层级；不删除数据状态、目标名、草稿入口或必要操作。旧脚本及兼容样式保持现有资源文件边界，以维持静态预览和热更资源白名单；大文件拆分提示记录为后续维护事项，不混入业务重构。

## 验收

手机 390×844 与桌面 1440×960，补充 320px 窄屏、横屏、200% 缩放的等效 CSS 视口、长中文目标、夜间与减少动态效果。真实临时账号验证新手引导、草稿刷新恢复、离线限制、附件保留、航程编辑、调研、归档和账号隔离；外部 AI/检索使用合成服务，不调用用户真实密钥。测试与截图在 `artifacts/oil-ui/`，私有测试目录用后清理。独立视觉评审与最终测试结果见发布报告。
