# 栖伴 · 航海手账 UI · 热更 8

版本：0.9.2-beta.1；热更序号：8；原生运行时：qiban-native-2。

## 设计与实现

使用 oil-oil/oil-ui 0.23.9 的存量界面优化流程，沿用航海、栖栖和船的产品语言。方向是“安静的航海手账”：白天纸色与植被绿，夜间深海与浅绿；统一标题、正文、输入、按钮、弹窗、圆角与间距。设计规则见 `design/oil-ui-journal.md`。

- 桌面改为左侧导航，海景与当前行动分栏；手机保留底部四项导航，缩短海景占高。
- 海图、日志、群岛、引导和登录页共用同一套色彩及控件规则。
- 手机输入至少 16px，主按钮 56px；兼顾安全区域、320px 窄屏、横屏、长中文目标、键盘和减少动态效果。
- 进入时 320ms 轻移入，弹窗 220ms，按钮按下与导航反馈 160ms；保留长按升帆、取消、下锚、完成与返航反馈。主题背景直接切换，避免旧背景过渡产生浅底浅字。
- 删除重复的“群岛”标题、没有当前航程内容的回顾标题和日志重复分隔线；压缩调研说明，保留外发范围、服务额度与每日限制。
- 没有修改账号协议、数据格式、AI/检索接口和原生权限，没有引入外部字体、素材或依赖。
