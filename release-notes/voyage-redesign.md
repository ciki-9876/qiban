# 远航：主题与上手体验重构

把“月面”换成“远航”，同时按新手试用的问题重排上手路径。只改网页资源，数据格式和四端原生部分不变。

## 用户能看到的变化

- 第一次打开先上一座练习岛，目标是「学会使用栖伴」。三段航程各一程：按住帆绳 → 打开海图 → 翻翻日志，中间过浮标，最后登岛。海图、日志、群岛在练习时各有一句提示。随时可以跳过；如果练习岛还没用过，开始自己的岛时会把它移除。
- 自己的岛用三步设定：想去哪座岛、分几段航程（默认 出发 / 中途 / 靠岸）、今天的第一程。不再把开发者自己的示例目标塞给新用户。只有从没动过的内置示例才会被替换，用过的会原样保留。
- 首页一屏：海、船、岛和“今天这一程”。完成只有一个动作——按住帆绳。这一程会直接写进航线，日志可写可不写。
- 导航改为 海上 / 海图 / 日志 / 群岛。“带回”并入日志的“漂流瓶”。
- 海图里管理航程：加一程、改航程名、加一段航程、过浮标、准备靠岸。
- 靠岸仪式：每段航程变成岛上的地标，写进航线的每一程变成沙滩上的贝壳，给岛起名后收进群岛。
- 没连 AI 时，不显示依赖 AI 的按钮。
- 界面主文案不再出现 版本 / 轮 / 采用 / 收尾 / 归档 / 行动 这些词。

## 兼容

- 存储结构仍是 workspace schema 2 / project schema 1。新增的可选字段：project.islandName、project.tutorial（练习岛），以及 attempt.quick（按帆绳完成、尚未写日志）。
- “按帆绳”会新建一条记录并把它设为 accepted；旧记录不会被改写。
- 新建目标允许后面几段航程暂时没有行动，但至少要有一程。
- Service Worker 缓存键升到 r4。

## 发布

这次只改了网页资源，可以按 `clients/UPDATES.md` 用下一个序号签名发布 UI 更新。签名需要本机私钥，所以这一步要由维护者来做。
